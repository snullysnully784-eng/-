📝 تاقیکردنەوەی بیرکاری - بەشی یەکەم

بابەتەکان: کێشانی وێنەی نەخشەکان، یەکتربڕین لەگەڵ تەوەرەکان، هاوجێبوون، دۆزینەوەی خاڵەکان
١. (هاوجێبوون) جۆری هاوجێبوونی نەخشەی $f(x) = \frac{x \cdot |x|}{x^2 + 1}$ دیاری بکە:
✅ وەڵامی ڕاست: B) نەخشەیەکی تاکە
💡 شیکاری: تاقیکردنەوە بە $f(-x)$ دەکەین:
$f(-x) = \frac{(-x)|-x|}{(-x)^2 + 1} = \frac{-x|x|}{x^2 + 1} = -f(x)$.
چونکە $f(-x) = -f(x)$ ەیە، کەواتە نەخشەکە تاکە.
٢. (دۆزینەوەی خاڵ) ژمارەی خاڵەکانی یەکتربڕینی ئاسۆیی ($x$) بۆ نەخشەی $f(x) = (x^2 - 4)\sqrt{x - 1}$ چەندە؟
✅ وەڵامی ڕاست: B) ۲ خاڵ: $(2,0), (1,0)$
💡 شیکاری: سەرەتا بواری نەخشەکە $x \ge 1$ ەیە.
بە دانانی $f(x) = 0$: $x^2 - 4 = 0 \Rightarrow x = \pm 2$ وە $\sqrt{x-1} = 0 \Rightarrow x = 1$.
بەڵام $x = -2$ لە ناو بواردا نییە و ڕەت دەکرێتەوە. کەواتە تەنها ۲ خاڵ دەمێننەوە.
٣. (یەکتربڕین لەگەڵ تەوەرەکان) خاڵی یەکتربڕینی ئەستوونی ($y$) بۆ نەخشەی $f(x) = \frac{x^2 - 9}{x + 3}$ بریتییە لە:
✅ وەڵامی ڕاست: A) $(0, -3)$
💡 شیکاری: بۆ دۆزینەوەی یەکتربڕین لەگەڵ تەوەری $y$، بەهای $x = 0$ دادەنێین:
$f(0) = \frac{0^2 - 9}{0 + 3} = \frac{-9}{3} = -3$. کەواتە خاڵەکە بریتییە لە $(0, -3)$.
٤. (کێشانی وێنەی نەخشەکان) ڕوونکردنەوەی نەخشەی $g(x) = |x - 3| + 2$ بەبەراورد لەگەڵ $f(x) = |x|$ چۆن دەگوازرێتەوە؟
✅ وەڵامی ڕاست: B) ۳ یەکە بۆ لای ڕاست و ۲ یەکە بۆ سەرەوە
💡 شیکاری: گۆڕانی ئاسۆیی: $|x - 3|$ واتە ۳ یەکە بۆ ڕاست. گۆڕانی ئەستوونی: $+ 2$ واتە ۲ یەکە بەرەو سەرەوە.
٥. (هاوجێبوون) نەخشەی $f(x) = x^4 - 3x^2 + 5$ هاوجێیە بە دەوری چی؟
✅ وەڵامی ڕاست: C) دەوری تەوەری $y$
💡 شیکاری: نەخشەکە جووتە چونکە تەواوی تواناکانی جۆری جووتن ($4, 2, 0$). هەموو نەخشەیەکی جووت هاوجێیە بە دەوری تەوەری $y$.
٦. (دۆزینەوەی خاڵ) خاڵەکانی یەکتربڕینی دوو نەخشەی $f(x) = x^2$ و $g(x) = 2x + 3$ برێتین لە:
✅ وەڵامی ڕاست: A) $(3, 9)$ و $(-1, 1)$
💡 شیکاری: هەردوو نەخشە یەکسان دەکەین: $x^2 = 2x + 3 \Rightarrow x^2 - 2x - 3 = 0$.
شیکار بە شیکردنەوە: $(x - 3)(x + 1) = 0 \Rightarrow x = 3$ یان $x = -1$.
بە دانانی بەهاکان: $f(3) = 9$ و $f(-1) = 1$.
٧. (کێشانی وێنەی نەخشەکان) ئەگەر وێنەی نەخشەی $f(x) = \sqrt{x}$ ئاوێنە بکرێتەوە بە دەوری تەوەری $x$ دا و دواتر ۱ یەکە ببڕێتە خوارەوە، هاوکێشە نوێیەکە چییە؟
✅ وەڵامی ڕاست: B) $g(x) = -\sqrt{x} - 1$
💡 شیکاری: ئاوێنەکردنەوە بە دەوری تەوەری $x$ نیشانەی منفی لە دەرەوەی نەخشەکە دادەنێت ($-\sqrt{x}$). دواتر ۱ یەکە دابەزین بۆ خوارەوە $- 1$ دەبێت.
٨. (یەکتربڕین لەگەڵ تەوەرەکان) نەخشەی $f(x) = \frac{x^2 + 1}{x - 2}$ لە چ خاڵێکدا تەوەری $x$ دەبڕێت؟
✅ وەڵامی ڕاست: D) هیچ خاڵێکی یەکتربڕینی لەگەڵ تەوەری $x$ نییە
💡 شیکاری: بۆ تەوەری $x$ دەبێت بەشی سەرەوە یەکسان بێت بە صفر: $x^2 + 1 = 0 \Rightarrow x^2 = -1$ کە ئەمەش لە ژمارەی ڕاستەقینەدا ناکرێت، بۆیە یەکتربڕینی نییە.
٩. (هاوجێبوون) نەخشەی $f(x) = x^3 - 4x$ ڕاستییەکەی بەم شێوەیەیە:
✅ وەڵامی ڕاست: B) نەخشەی تاکە و هاوجێیە بە دەوری خاڵی بنەڕەت $(0,0)$
💡 شیکاری: $f(-x) = (-x)^3 - 4(-x) = -x^3 + 4x = -(x^3 - 4x) = -f(x)$. بەمەش نەخشەکە تاکە و هاوجێیە بە دەوری بنەڕەت.
١٠. (کێشانی وێنە و دۆزینەوەی خاڵ) سەرکەوانەی نەخشەی دووجای $f(x) = 2(x - 1)^2 + 3$ بریتییە لە چ خاڵێک؟
✅ وەڵامی ڕاست: B) $(1, 3)$
💡 شیکاری: لە شێوەی گشتی $f(x) = a(x - h)^2 + k$ خاڵی سەرکەوانە بریتییە لە $(h, k)$. لێرەدا $h = 1$ و $k = 3$ ەیە، کەواتە سەرکەوانەکە $(1, 3)$ ەیە.
